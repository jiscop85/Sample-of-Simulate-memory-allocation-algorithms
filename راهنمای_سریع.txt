■ پیش‌نیاز (فقط یک بار روی هر سیستم)
  Python 3.8 یا بالاتر
  دانلود: https://www.python.org/downloads/
  ⚠ هنگام نصب حتماً تیک "Add Python to PATH" را بزنید!


■ ویندوز — ساده‌ترین روش (۱ کلیک!)
  ┌─────────────────────────────────────────────────────────────┐
  │  دوبار کلیک روی:  INSTALL_AND_RUN.bat                      │
  │  (نصب خودکار + اجرای GUI — همه‌چیز در یک کلیک)             │
  └─────────────────────────────────────────────────────────────┘

■ ویندوز — روش دو مرحله‌ای
  ┌─────────────────────────────────────────────────────────────┐
  │  ۱) دوبار کلیک روی:  setup.bat     (فقط بار اول)         │
  │  ۲) دوبار کلیک روی:  start.bat     (هر بار اجرا)         │
  └─────────────────────────────────────────────────────────────┘


■ ویندوز — خط فرمان (بدون GUI)
  دوبار کلیک روی:  start_cli.bat


■ لینوکس / مک
  chmod +x setup.sh start.sh
  ./setup.sh          # بار اول
  ./start.sh          # هر بار اجرا


■ روش جایگزین (همه سیستم‌عامل‌ها)
  python setup_project.py install --run


■ انتقال به سیستم دیگر
  ۱) کل پوشه پروژه را کپی کنید (USB، ایمیل، ZIP و ...)
  ۲) پوشه .venv را کپی نکنید (روی سیستم جدید خودکار ساخته می‌شود)
  ۳) روی سیستم جدید setup.bat را اجرا کنید

  یا از pack_for_transfer.bat استفاده کنید تا ZIP آماده بسازد.


■ ساختار فایل‌های مهم
  setup.bat          → نصب خودکار
  start.bat          → اجرای GUI
  start_cli.bat      → اجرای منوی متنی
  main.py            → نقطه ورود برنامه
  requirements.txt   → لیست کتابخانه‌ها
  samples/           → نمونه‌های آماده


■ عیب‌یابی
  مشکل: Python پیدا نمی‌شود
  → Python را نصب کنید و PATH را فعال کنید، سیستم را Restart کنید

  مشکل: خطای pip یا matplotlib
  → setup.bat را دوباره اجرا کنید

  مشکل: GUI باز نمی‌شود
  → در CMD بنویسید:
    cd مسیر_پروژه
    .venv\Scripts\activate
    python main.py --gui
