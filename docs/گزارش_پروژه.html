گزارش پروژه: شبیه‌سازی الگوریتم‌های تخصیص حافظه

درس: سیستم‌عامل | زبان: Python 3.8+ | الگوریتم‌ها: First Fit, Best Fit, Worst Fit

۱. مقدمه

این پروژه شبیه‌ساز مدل تقسیم‌بندی ثابت حافظه (Fixed Partition) است. هدف، مقایسه سه الگوریتم کلاسیک تخصیص حافظه و تحلیل Internal Fragmentation و Memory Utilization می‌باشد.

۲. شرح مسئله

  • مجموعه‌ای از بلوک‌های حافظه با اندازه ثابت
  • مجموعه‌ای از پردازه‌ها با نیاز حافظه مشخص
  • هر بلوک حداکثر یک پردازه می‌پذیرد
  • پردازه فقط در بلوکی با اندازه کافی قرار می‌گیرد

۳. الگوریتم‌ها

۴. فرمول‌ها

Internal Fragmentation = Block Size - Process Size
Memory Utilization = (Used Memory / Total Memory) × 100

۶. تحلیل

در این نمونه، Best Fit بهترین نتیجه را داشت: تمام پردازه‌ها تخصیص یافتند، fragmentation کمتر و utilization بالاتر بود. Worst Fit بیشترین فضای هدررفته را ایجاد کرد.

۷. خروجی برنامه

  • رابط گرافیکی (GUI) با نقشه حافظه و نمودار
  • گزارش متنی: output/report.txt
  • نمودار PNG: output/comparison_chart.png
  • نقشه حافظه: output/memory_maps/

۸. نتیجه‌گیری

انتخاب الگوریتم تخصیص حافظه تأثیر مستقیم بر بهره‌وری دارد. Best Fit در اکثر نمونه‌های آموزشی گزینه بهتری برای کاهش fragmentation است.
