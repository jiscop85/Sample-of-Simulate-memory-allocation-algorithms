# اسلایدهای ارائه — شبیه‌سازی تخصیص حافظه

---

## اسلاید ۱ — عنوان
# شبیه‌سازی الگوریتم‌های تخصیص حافظه
### First Fit · Best Fit · Worst Fit
تحلیل Internal Fragmentation و Memory Utilization

---

## اسلاید ۲ — مسئله چیست؟
- سیستم‌عامل باید حافظه را به پردازه‌ها بدهد
- مدل: **بلوک‌های ثابت** (Fixed Partition)
- هر بلوک = یک پردازه
- سؤال: **کدام الگوریتم بهتر است؟**

---

## اسلاید ۳ — ورودی برنامه
```
بلوک‌ها:   100, 500, 200, 300, 600 KB
پردازه‌ها: 212, 417, 112, 426 KB
کل حافظه: 1700 KB
```

---

## اسلاید ۴ — سه الگوریتم

| الگوریتم | قانون انتخاب |
|----------|--------------|
| First Fit | اولین بلوک مناسب |
| Best Fit | کوچک‌ترین بلوک مناسب |
| Worst Fit | بزرگ‌ترین بلوک مناسب |

---

## اسلاید ۵ — Internal Fragmentation
```
Fragmentation = اندازه بلوک − اندازه پردازه
```
فضای هدررفته **داخل** بلوک تخصیص‌یافته

---

## اسلاید ۶ — نتایج مقایسه

| | First Fit | Best Fit | Worst Fit |
|---|-----------|----------|-----------|
| تخصیص | 3/4 | **4/4** | 3/4 |
| Frag. | 559 | **433** | 659 |
| Util. | 43.6% | **68.7%** | 43.6% |

- کمترین fragmentation
